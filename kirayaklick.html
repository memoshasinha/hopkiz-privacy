KirayaKlick Privacy Policy

Last updated: 2 September 2026
Developer: Memosha Sinha
Privacy contact: msinha2801@gmail.com

KirayaKlick is an offline home and rental record organiser for owners and tenants. It helps users manage property details, tenancy information, rent notes, maintenance, warranty records, cleaning routines, reminders, and selected document references.

Data handled on the device

KirayaKlick does not require an online account, password, location, SMS, call-log, contacts, camera, or network permission. Profile name and role, property details, tenant name and contact details, tenancy dates, rent and deposit notes, maintenance entries, warranty details, cleaning tasks, reminders, and selected attachment references are stored only in private device storage.

Selected files

When a user chooses a photo or PDF, Android’s system file picker provides access only to that selected file. KirayaKlick keeps a reference so the user can return to it; it does not upload the file to servers. Original files remain in their original device location. Users should not add Aadhaar, PAN, passport, bank login, card details, or other unnecessary sensitive identity information.

Retention and deletion

Users can remove records inside the app. Uninstalling KirayaKlick removes its private app data; original photos and PDFs saved elsewhere on the device are not deleted by KirayaKlick.

Sharing

KirayaKlick does not send property, tenancy, rent, contact, maintenance, or document data to servers or share it with advertisers, analytics providers, landlords, tenants, contractors, or other third parties. When a user taps a share button, Android opens a sharing app chosen by the user.

Security

KirayaKlick uses Android private app storage. It is a record organiser, not an identity-verification, legal, payment, or property-management service.

Changes and contact

We may update this policy when the app changes. For privacy questions, contact msinha2801@gmail.com.
